# My Resume (powered by Delta CV)

This repository contains my personal resume data, managed automatically by
[Delta CV](https://github.com/delta-cv/delta).

## Setup

1. Edit `config.json` — set `login` to your GitHub username and configure your LLM provider.
2. Copy `.env.local.example` to `.env.local` and fill `GITHUB_TOKEN` and `LLM_API_KEY`.
3. For local development, run Delta CV from the source checkout until the Action flow is enabled.
4. Run `observe`, `evolve`, `tailor`, then `lint` as shown below.

Missing `LLM_API_KEY` is valid only before you run `evolve`.

## What Gets Collected

Delta CV does not clone all of your repositories.

`observe` reads GitHub activity through the GitHub GraphQL and REST APIs:

- commit contributions by repository and date, with commit counts
- pull requests: title, URL, state, additions, deletions, changed file count, merge time
- issues: title, URL, state
- reviews: reviewed PR title, URL, repository, submitted time

It writes normalized event records under `data/events/`. Repository source code is not downloaded.

## Files

| Path | Description |
|------|-------------|
| `config.json` | Delta configuration |
| `.env.local` | Local secrets, ignored by git |
| `data/` | Raw event and experience data (committed for auditability) |
| `data/_meta/experience.json` | Structured experience generated by `evolve` |
| `data/tailored/` | Generated resume Markdown files |

## Local Test Flow

From this resume repository:

```bash
cp .env.local.example .env.local
```

Edit `.env.local`:

```bash
GITHUB_TOKEN=github_pat_or_classic_token
LLM_API_KEY=your_llm_api_key
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat
```

Run the pipeline from your Delta source checkout:

```bash
node /path/to/delta/dist/cli.js observe --since 2026-01-01
node /path/to/delta/dist/cli.js evolve --since 2026-01-01
node /path/to/delta/dist/cli.js tailor
node /path/to/delta/dist/cli.js lint --file data/tailored/default.md --lang zh
```

Use a recent `--since` date for the first test so the LLM step has fewer events to process.

Expected outputs:

```text
data/events/*.jsonl
data/_meta/cursor.json
data/_meta/experience.json
data/snapshots/*.json
data/tailored/default.md
```
